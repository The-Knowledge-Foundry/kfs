# Design Debt

Design debt records architectural questions intentionally postponed.

## Open Questions

- Should Working Context become part of KFS or remain a project artifact?
- Should hypotheses become first-class specification concepts?
- Should provenance begin at capture or at accepted knowledge?
- Should maturity be modeled as states or transitions?
- Should Knowledge Foundry define a knowledge lifecycle or only describe concepts?
- Should the repository or accepted specification be considered the ultimate source of truth?
